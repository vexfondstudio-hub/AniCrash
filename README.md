# AniCrash - Аниме Онлайн Без Рекламы 🚀

AniCrash — это современная веб-платформа для просмотра аниме в высоком качестве (до 1080p) абсолютно без рекламы. Приложение оптимизировано для плавной работы даже с огромными библиотеками (например, One Piece с 1100+ сериями).

## ✨ Особенности

- 🎬 **HLS Плеер**: Плавное воспроизведение с выбором качества (480p/720p/1080p) и автоматическим пропуском интро.
- ⚡ **Ультра-Оптимизация**: Использование `React.memo`, виртуализации списков и дебаунсинга поиска для мгновенной работы интерфейса.
- 📱 **Mobile Ready**: Адаптивный дизайн, который ощущается как нативное мобильное приложение на смартфонах.
- 🖤 **Dark Premium Theme**: Стильный темный интерфейс с акцентами в цвете Rose.
- 🔍 **Умный поиск и фильтры**: Мгновенная фильтрация по жанрам, годам и типам.
- 🏴‍☠️ **Специально для One Piece**: Интеллектуальное заполнение и навигация по всем 1100+ сериям.

## 🛠️ Стек технологий

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS 4.
- **Animations**: Framer Motion.
- **Backend**: Node.js, Express (для продакшн-хостинга).
- **API**: Интеграция с AniLibria API.

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- npm или yarn

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/anicrash.git
   cd anicrash
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```

### Деплой
Для сборки проекта и запуска в продакшн-режиме:
```bash
npm run build
npm start
```

## 📂 Структура проекта
- `src/components` — UI компоненты (Плеер, Карточки, Баннеры).
- `src/services` — Логика работы с API и авторизацией.
- `src/data` — Локальные базы данных и константы.
- `server.ts` — Express сервер для хостинга статики и API.
